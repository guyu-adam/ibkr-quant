## 新 P1 — 本周可做（提升质量）

### 1. main.py 添加 main() 函数
pyproject.toml 声明了 `quant = "main:main"` 入口点，但 main.py 用 `if __name__ == "__main__"` 模式，没有 `main()` 函数。添加后可用 `pip install -e . && quant --status`。
**工时**：15 分钟

### 2. 消除 main.py 的 sys.path.insert
pip install -e . 安装后所有导入会自动解析，不再需要 sys.path hack。
**工时**：与 #1 一起做

### 3. Options/事件驱动策略接入引擎
options.py 的 `generate_signals()` 和 leverage.py 的 `screen_and_trade()` 目前都需要通过 `on_bar()` 以外的方式触发。建议在 engine 中添加可选的日终/每小时 hook。
**工时**：2-3 小时

### 4. README badge 版本号同步
pyproject.toml 声明 `>=3.10`，README 仍写 `3.9+`。
**工时**：1 分钟

## P0 — 立即修复（系统无法运行）

### 1. 修复 `WATCHLIST` 导入错误

**现象**：`python main.py --backtest` 崩溃  
**原因**：`main.py:24` 和 `core/engine.py:16` 导入 `WATCHLIST`，但 `settings.py` 中定义的是 `US_WATCHLIST`  
**修复**：在 `settings.py` 中添加 `WATCHLIST = US_WATCHLIST` 别名，或将所有引用改为 `US_WATCHLIST`  
**工时**：5 分钟

### 2. 修复 `core/engine.py` 死导入

**现象**：`core/engine.py` 完全无法导入  
**修复方案 A（推荐）**：删除 `core/engine.py`，以 `paper_trading/engine.py` 为基础重构统一引擎  
**修复方案 B**：更正两条 import 路径，使其指向 v3 代码  
**工时**：30 分钟（方案 A 需额外 2-3 小时合并引擎）

### 3. 验证并修复 `_in_cluster()` HRP 函数

**现象**：`strategies/long_term.py` 中 `_in_cluster()` 的 `idx` 参数未被使用，HRP 权重计算可能全错  
**修复**：
1. 先用已知数据集手动验证 HRP 输出（与 PyPortfolioOpt 的 HRP 结果对比）
2. 确定逻辑正确性后再决定是否修改  
**工时**：1-2 小时（含验证）

## P1 — 本周内（影响核心功能）

### 4. 统一 Broker 接口

**问题**：`IBKRBroker.positions()` / `OKXBroker.positions()` / `SimulationBroker.positions()` 返回三种不同格式，`RiskManager.approve()` 按一种格式处理，跨界使用会崩溃  
**方案**：定义 `BrokerInterface` ABC，统一 `positions() → dict[str, float]`，`net_liquidation() → float`  
**工时**：2-3 小时

### 5. 补齐风控测试

**问题**：`kelly_fraction()`、`get_atr_multiplier()`、`record_trade()`、`update_intraday_peak()`、周度熔断 — 全部零测试  
**方案**：为核心风控算法补测试，特别是凯利公式的边界情况（全胜/全败/胜率 50%）  
**工时**：2 小时

### 6. 策略接口规范化

**问题**：`MeanReversionStrategy.evaluate()` 签名与 `BaseStrategy.on_bar()` 不同，`CointegrationPairStrategy.on_bar()` 始终返回 `[]`  
**方案**：每个策略的 `on_bar()` 必须能独立产生信号，或明确标记为 event-driven 并在文档中说明触发方式  
**工时**：3-4 小时

### 7. 消除 RSI 重复实现

**问题**：RSI 计算在 5 个文件中各自实现，算法一致但参数处理略有不同  
**方案**：在 `core/indicators.py` 中统一实现，其他模块改为导入  
**工时**：1 小时

## P2 — 本月内（提升工程质量）

### 8. 配置外部化

**问题**：API Key 以空字符串写在 `settings.py`，实际使用需编辑版本控制的代码  
**方案**：引入 `python-dotenv`，从 `.env` 加载（已在 requirements.txt 但未使用）  
**工时**：30 分钟

### 9. 补充策略测试

**问题**：6 个策略模块零测试  
**方案**：
- 优先测 `fast_trading.py`（最完整）和 `contracts.py`（有状态持久化）
- 用 mock broker 跑端到端信号→交易链路  
**工时**：4-6 小时

### 10. 补充核心模块测试

**问题**：`EnsembleEngine`、`RegimeDetector`、`MetaLabeler`、`WalkForwardValidator` 零测试  
**工时**：3-4 小时

### 11. 清理死依赖

**问题**：`requirements.txt` 中 7 个包从未被导入：`quantstats`、`PyPortfolioOpt`、`ta`、`beautifulsoup4`、`lxml`、`optuna`、`schedule`  
**工时**：15 分钟

### 12. Meta-Labeling fail-open 修复

**问题**：`filter_signal()` 异常时返回 `True`（允许交易），风控组件不应 fail-open  
**方案**：异常时返回 `False` 并记录错误日志  
**工时**：5 分钟

## P3 — 下季度（功能补全）

### 13. Options 策略实现

当前全是 `return []` stub。需要：
- 接入 IBKR 期权链数据
- 实现 Covered Call 的 delta/DTE 筛选逻辑
- 实现 Protective Put 的对冲比率动态调整
- 实现 Iron Condor 的 wing width 计算
**工时**：1-2 周

### 14. Schwab / THS 接口补全

- Schwab：实现 OAuth 2.0 流程、账户查询、下单
- THS：接入同花顺客户端交易协议（或换成东方财富 API）

### 15. Transformer 模型修复

- 添加 causal mask（防止数据泄露）
- 修正 decoder-only 架构（当前 cross-attention 用全零 memory）
- 添加训练早停和学习率调度
**工时**：3-5 天

当前 `WalkForwardValidator` 过于简陋：
- 无交易成本建模
- 无滑点模拟
- 无持仓期跟踪
- 建议基于 `paper_trading/engine.py` 的 `SimulationBroker` 扩展
**工时**：1-2 周

### 17. CI/CD 流水线

- GitHub Actions: 每次 push 跑 `pytest` + `flake8` + `mypy`
- pre-commit hooks: black + isort + flake8
- 覆盖率门槛
**工时**：半天

### 18. 项目打包

- 添加 `pyproject.toml` / `setup.cfg`
- `pip install -e .` 可安装
- 消除所有 `sys.path.insert` 操作
**工时**：半天

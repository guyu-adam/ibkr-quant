## 剩余问题

### 需要关注

1. **main.py 仍有 sys.path.insert** — pyproject.toml 已配置，可通过 pip install -e . 消除此 hack
2. **IBKRBroker.last_price() 仍 sleep(1)** — 阻塞式等待，高频场景有影响
3. **contracts.py 仍硬编码 grid_state.json** — 多实例会冲突
4. **Python 版本要求提升到 3.10+** — pyproject.toml 写 >=3.10，README badge 仍写 3.9+
5. **Options 策略 on_bar() 仍返回 []** — 核心逻辑在 generate_signals()，需通过 engine 以外的路径调用
6. **CointegrationPairStrategy / 慢速策略 on_bar() 仍返回 []** — 事件驱动策略未接入调度器

### 建议

- 补一个 pip install -e . 到 README 安装步骤
- 为 crypto/ 模块决定去留（OKX 接口已融入 interfaces/okx.py）
- 写一个集成测试：BacktestBroker → 策略 → 回测报告 端到端

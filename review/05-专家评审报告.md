**修复质量：优秀**

### ✅ P0 — `core/regime_detector.py`：HMM 训练失败后可以重试

**修复质量：良好，有一处细节值得关注**

引入了指数退避重试：
```python
retry_interval = min(HMM_RETRAIN_FREQ * (1 + self._failed_attempts),
                     self._max_retry_interval)
```

逻辑正确，失败次数越多等待越久，最终收敛到 `HMM_RETRAIN_FREQ * 2`。

**需要注意**：`_failed_attempts` 只在 `ImportError` 和 `Exception` 时递增，但 `should_retrain = False` 路径直接 `return`，不会重置。这没有问题，但如果将来增加更多提前返回的路径，要注意保持逻辑一致。

## 二、仍未修复的问题

### ❌ P0 — `core/engine.py`：多策略只跑第一个

这是初审中列出的**最高优先级问题**，这次提交没有涉及。

```python
# 现状仍然是：
result = self._strategies[0].evaluate(...)
```

注册的 6 个策略，实际只执行第一个。`EnsembleEngine` 的多策略融合逻辑形同虚设。

**这是系统架构层面的核心缺陷，必须修复。**

修复方向：
```python
all_signals = []
for strategy in self._strategies:
    sig = strategy.evaluate(feed, symbol, broker, risk)
    if sig.get("signal") != "hold":
        all_signals.append((strategy.name, sig))

# 传给 EnsembleEngine 融合
final_signal = ensemble.combine(all_signals)
```
